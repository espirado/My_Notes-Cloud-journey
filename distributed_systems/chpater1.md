 Separating policy from mechanism
    - consideration for caching mechasing 
         - storage where the data is to be cached 
         - Exemption when cache fills up which data to be removed 
         - Refresh when does browser check if cached data is still up-to-date
         - sharing does the browser make use of a private cache or cache to be shared among browsers
    Separation between policy and mechanism. in the case of web caching the browser should  ideally provide favility for only storing documents.(mechanism) and at the same time allow users to decide which documents are stored and for how long(policy).
